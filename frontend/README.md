# HealthVault AI

Create a modern AI-powered Personal Health Record (PHR) web application called "MedVault".

IMPORTANT:

This is NOT a hospital management system.

Do NOT create doctor portals, hospital dashboards, departments, or staff management.

MedVault is a personal health vault where a user can:

- Store medical records

- Upload medical reports

- Understand health information using AI

- Track health trends

- Generate emergency QR access

Design a premium healthcare AI application.

STYLE:

- Modern healthcare SaaS design

- Dark navy background

- White text

- Blue and purple accents

- Glassmorphism cards

- Rounded corners

- Clean spacing

- Responsive desktop and mobile design

- Professional like Apple Health + Linear + Notion
